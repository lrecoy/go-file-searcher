# Go File Searcher

## Project Description
Go File Searcher is a command-line application written in Go. The goal is to make it easier to find files on a computer by searching through directories and their subdirectories.

## Current Progress
- Set up the Go development environment in VS Code.
- Created the initial Go project and module.
- Implemented recursive directory traversal.
- Displayed file paths found within a selected directory.

## How to Run
Make sure Go is installed. Open a terminal in the project directory and run:

go run main.go .

Replace "." with the path of the directory you want to search.
